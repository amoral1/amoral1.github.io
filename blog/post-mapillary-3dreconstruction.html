Overview

A research pipeline for metric 3D reconstruction, trajectory evaluation, and Gaussian Splatting from Mapillary street-level imagery — comparing feed-forward transformer backbones on sequential Tokyo drive sequences. All runs tracked via MLflow on DagsHub.

Study area: two driving sequences through Tokyo, Japan — ~870 raw Mapillary frames per sequence, sampled at stride 5 (~174 inference frames) or stride 1 (100-frame dense subsets).

Key Technical Notes

Pi3 Confidence Scale

Pi3 confidence values max at ~0.5, not ~5 like VGGT-Long. CONF_THRESHOLD must be set to 0.05 for Pi3 runs or the point cloud filters to near-empty.

COLMAP Camera Resolution

cameras.txt must use actual image dimensions (518×392), not the model's internal output resolution (574×434 for Pi3). Intrinsics are scaled proportionally: fx_scaled = fx_model × (W_img / W_model).

Forward-Facing Sequence Limitation

Forward-facing drive sequences (camera always pointing ahead) lack lateral baseline — the same point is never seen from multiple angles, which limits both trajectory accuracy and splat quality. The next experiment uses a Mapillary loop sequence (start/end within ~50m) to enable real multi-view triangulation and SALAD loop closure.

Eval() String Bug — VGGT-Long

OmegaConf parses float config values; VGGT-Long calls eval() on them internally. Fix:

cfg.Model.IRLS.tol = str(IRLS_TOL)                   # "1e-9"
cfg.Loop.SIM3_Optimizer.lambda_init = str(1e-6)       # "1e-06"
